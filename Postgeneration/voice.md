# Настройки формирования поста (Voice)

## Архитектура
Посты генерируются нейросетью через OpenAI-совместимый proxy API.
Пользователь вводит **ссылку на товар**, сервер парсит страницу,
отправляет данные нейросети — и получает готовый пост.

---

## Настройки API (app.py, блок «НАСТРОЙКИ PROXY API»)

### API_URL
- **Что это:** адрес proxy API
- **По умолчанию:** `https://api.openai.com/v1`
- **Где менять:** строка `API_URL`
- **Примеры:**
  - `https://api.openai.com/v1` — официальный OpenAI
  - `https://api.proxyapi.ru/v1` — пример российского proxy
  - Любой другой OpenAI-совместимый endpoint

### MODEL
- **Что это:** название языковой модели
- **По умолчанию:** `gpt-4o-mini`
- **Где менять:** строка `MODEL`
- **Варианты:** `gpt-4o`, `gpt-4o-mini`, `claude-3-haiku`, `gemini-1.5-flash` и др.
  (зависит от того, что поддерживает ваш proxy)

### API_KEY
- **Что это:** ключ API (можно оставить пустым и вводить на сайте)
- **Где менять:** строка `API_KEY`
- **Важно:** если оставить пустым, пользователь должен вводить ключ вручную

## Настройки генерации (app.py, блок «НАСТРОЙКИ ГЕНЕРАЦИИ»)

### MAX_PAGE_TEXT
- **Что это:** максимальное количество символов текста,
  извлечённого со страницы товара (для экономии токенов)
- **По умолчанию:** 4000
- **Где менять:** строка `MAX_PAGE_TEXT`

### LANGUAGE
- **Что это:** язык поста
- **По умолчанию:** `ru`
- **Где менять:** строка `LANGUAGE`

## Настройки нейросети (app.py, блок «ЗАПРОС К НЕЙРОСЕТИ»)

### SYSTEM_PROMPT
- **Что это:** системный промпт, задающий роль и правила копирайтера
- **Где менять:** строка `SYSTEM_PROMPT`
- **Можно редактировать:**
  - Требования к длине поста
  - Количество эмодзи
  - Количество хештегов
  - Формат вывода
  - Дополнительные правила

### MOOD_PROMPTS
- **Что это:** описание каждого настроения для нейросети
- **Где менять:** словарь `MOOD_PROMPTS` (строки ~55–98)
- **Можно:**
  - Менять текст已有的 настроений
  - Добавлять новые настроения (и добавить `<option>` в HTML)
  - Удалять ненужные

### Температура модели
- **Где менять:** строка `'temperature': 0.85` в функции `call_llm()`
- **0.0–0.3:** консервативные, предсказуемые ответы
- **0.5–0.7:** баланс креативности и точности
- **0.8–1.0:** креативные, неожиданные ответы

## Как быстро настроить под себя

1. **Сменить proxy API** — поменяй `API_URL` и `API_KEY` в начале файла
2. **Сменить модель** — поменяй `MODEL`
3. **Изменить тон/правила** — отредактируй `SYSTEM_PROMPT`
4. **Добавить настроение** — добавь пункт в `MOOD_PROMPTS` и `<option>` в HTML
5. **Сделать посты длиннее/короче** — измени инструкцию в `SYSTEM_PROMPT`
6. **Изменить креативность** — поменяй `temperature`
